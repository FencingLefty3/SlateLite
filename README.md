## Installation

Install Slate Lite as a PWA.


- Windows (Chrome/Edge):
```bash
  Adress bar > Install
```
___
- Mac:
```bash
  Safari:
  File > Add to Dock
  Chrome:
  Adress Bar > Install
```
___
- iOS (Safari):
```bash
  Share > More/Scroll > Add to home screen (Web App)
```
___
- Android:
```bash
   3-dot menu > add to homescreen/install 
```
## Run Locally

Clone the project

```bash
  git clone https://github.com/FencingLefty3/SlateLite
```

Go to the project directory

```bash
  cd SlateLite
```

Start the LocalHost

```bash
  python -m http.server
```
